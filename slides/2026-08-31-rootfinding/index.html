An algorithm: Bisection¶

Bisection is a rootfinding technique that starts with an interval [a,b][a,b][a,b] containing a root and does not require derivatives. Suppose fff is continuous. What is a sufficient condition for fff to have a root on [a,b][a,b][a,b]?

hasroot(f, a, b) = f(a) * f(b) < 0

Bisection¶

function bisect(f, a, b, tol)
    mid = (a + b) / 2
    if abs(b - a) < tol
        return mid
    elseif hasroot(f, a, mid)
        return bisect(f, a, mid, tol)
    else
        return bisect(f, mid, b, tol)
    end
end

x0 = bisect(f, -1, 3, 1e-5)

Iterative bisection¶

  • Data structures often optimized for appending rather than prepending.

  • Bounds stack space

f(x) = cos(x) - x
hasroot(f, a, b) = f(a) * f(b) < 0
function bisect_iter(f, a, b, tol)
    hist = Float64[]
    while abs(b - a) > tol
        mid = (a + b) / 2
        push!(hist, mid)
        if hasroot(f, a, mid)
            b = mid
        else
            a = mid
        end
    end
    hist
end

Convergence classes¶

A convergent rootfinding algorithm produces a sequence of approximations xkx_kxk​ such that

lim⁡k→∞xk→x∗\lim_{k \to \infty} x_k \to x_*k→∞lim​xk​→x∗​
(5)

where f(x∗)=0f(x_*) = 0f(x∗​)=0. For analysis, it is convenient to define the errors ek=xk−x∗e_k = x_k - x_*ek​=xk​−x∗​. We say that an iterative algorithm is qqq-linearly convergent if

lim⁡k→∞∣ek+1∣/∣ek∣=ρ<1.\lim_{k \to \infty} |e_{k+1}| / |e_k| = \rho < 1.k→∞lim​∣ek+1​∣/∣ek​∣=ρ<1.
(6)

(The qqq is for “quotient”.) A smaller convergence factor ρ\rhoρ represents faster convergence. A slightly weaker condition (rrr-linear convergence or just linear convergence) is that

∣ek∣≤ϵk|e_k| \le \epsilon_k∣ek​∣≤ϵk​
(7)

for all sufficiently large kkk when the sequence {ϵk}\{\epsilon_k\}{ϵk​} converges qqq-linearly to 0.

Remarks on bisection¶

  • Specifying an interval is often inconvenient

  • An interval in which the function changes sign guarantees convergence (robustness)

  • No derivative information is required

  • If bisection works for f(x)f(x)f(x), then it works and gives the same accuracy for f(x)σ(x)f(x) \sigma(x)f(x)σ(x) where σ(x)>0\sigma(x) > 0σ(x)>0.

  • Roots of even degree are problematic

  • A bound on the solution error is directly available

  • The convergence rate is modest -- one iteration per bit of accuracy
