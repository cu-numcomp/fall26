using LinearAlgebra

function vander(x, k=nothing)
    if isnothing(k)
        k = length(x)
    end
    m = length(x)
    V = ones(m, k)
    for j in 2:k
        V[:, j] = V[:, j-1] .* x
    end
    V
end

function vander_chebyshev(x, n=nothing)
    if isnothing(n)
        n = length(x) # Square by default
    end
    m = length(x)
    T = ones(m, n)
    if n > 1
        T[:, 2] = x
    end
    for k in 3:n
        #T[:, k] = x .* T[:, k-1]
        T[:, k] = 2 * x .* T[:,k-1] - T[:, k-2]
    end
    T
end

function chebyshev_regress_eval(x, xx, n)
    V = vander_chebyshev(x, n)
    vander_chebyshev(xx, n) / V
end

Variational notation for derivatives¶

It’s convenient to express derivatives in terms of how they act on an infinitessimal perturbation. So we might write

δf=∂f∂xδx.\delta f = \frac{\partial f}{\partial x} \delta x .δf=∂x∂f​δx.
(1)

(It’s common to use δx\delta xδx or dxdxdx for these infinitesimals.) This makes inner products look like a normal product rule

δ(xTy)=yT(δx)+xT(δy).\delta(\mathbf x^T \mathbf y) = \mathbf y^T (\delta \mathbf x) + \mathbf x^T (\delta \mathbf y).δ(xTy)=yT(δx)+xT(δy).
(2)

A powerful example of variational notation is differentiating a matrix inverse

0=δI=δ(A−1A)=(δA−1)A+A−1(δA)0 = \delta I = \delta(A^{-1} A) = (\delta A^{-1}) A + A^{-1} (\delta A)0=δI=δ(A−1A)=(δA−1)A+A−1(δA)
(3)

and thus

δA−1=−A−1(δA)A−1\delta A^{-1} = - A^{-1} (\delta A) A^{-1}δA−1=−A−1(δA)A−1
(4)

Optimization for linear models¶

Given data (x,y)(x,y)(x,y) and loss function L(c;x,y)L(c; x,y)L(c;x,y), we wish to find the coefficients ccc that minimize the loss, thus yielding the “best predictor” (in a sense that can be made statistically precise). I.e.,

cˉ=arg⁡min⁡cL(c;x,y).\bar c = \arg\min_c L(c; x,y) .cˉ=argcmin​L(c;x,y).
(5)

It is usually desirable to design models such that the loss function is differentiable with respect to the coefficients ccc, because this allows the use of more efficient optimization methods. Recall that our forward model is given in terms of the Vandermonde matrix,

f(x,c)=V(x)cf(x, c) = V(x) cf(x,c)=V(x)c
(6)

and thus

∂f∂c=V(x).\frac{\partial f}{\partial c} = V(x) .∂c∂f​=V(x).
(7)

Derivative of loss function¶

We now differentiate our loss function

L(c;x,y)=12∥f(x,c)−y∥2L(c; x, y) = \frac 1 2 \lVert f(x, c) - y \rVert^2L(c;x,y)=21​∥f(x,c)−y∥2
(8)

using a more linear algebraic approach to write the same expression is

∇cL(c;x,y)=(f(x,c)−y)TV(x)=(V(x)c−y)TV(x)=V(x)T(V(x)c−y).\begin{align} \nabla_c L(c; x,y) &= \big( f(x,c) - y \big)^T V(x) \\ &= \big(V(x) c - y \big)^T V(x) \\ &= V(x)^T \big( V(x) c - y \big) . \end{align}∇c​L(c;x,y)​=(f(x,c)−y)TV(x)=(V(x)c−y)TV(x)=V(x)T(V(x)c−y).​​
(9)

A necessary condition for the loss function to be minimized is that ∇cL(c;x,y)=0\nabla_c L(c; x,y) = 0∇c​L(c;x,y)=0.

Gradient descent¶

Instead of solving the least squares problem using linear algebra (QR factorization), we could solve it using gradient descent. That is, on each iteration, we’ll take a step in the direction of the negative gradient.

function grad_descent(loss, grad, c0; gamma=1e-3, tol=1e-5)
    """Minimize loss(c) via gradient descent with initial guess c0
    using learning rate gamma.  Declares convergence when gradient
    is less than tol or after 500 steps.
    """
    c = copy(c0)
    chist = [copy(c)]
    lhist = [loss(c)]
    for it in 1:500
        g = grad(c)
        c -= gamma * g
        push!(chist, copy(c))
        push!(lhist, loss(c))
        if norm(g) < tol
            break
        end
    end
    (c, hcat(chist...), lhist)
end

f(x, c) = 1 ./ (c[1] .+ c[2].*x + c[3].*x.^2)
function gradf(x, c)
    f2 = f(x, c).^2
    [-f2 -f2.*x -f2.*x.^2]
end
function loss(c)
    r = f(x, c) - y
    0.5 * r' * r
end
function gradient(c)
    r = f(x, c) - y
    vec(r' * gradf(x, c))
end
