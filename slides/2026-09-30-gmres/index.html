using LinearAlgebra

function vander(x, k=nothing)
    if isnothing(k)
        k = length(x)
    end
    m = length(x)
    V = ones(m, k)
    for j in 2:k
        V[:, j] = V[:, j-1] .* x
    end
    V
end

function gram_schmidt_classical(A)
    m, n = size(A)
    Q = zeros(m, n)
    R = zeros(n, n)
    for j in 1:n
        v = A[:,j]
        R[1:j-1,j] = Q[:,1:j-1]' * v
        v -= Q[:,1:j-1] * R[1:j-1,j]
        R[j,j] = norm(v)
        Q[:,j] = v / R[j,j]
    end
    Q, R
end

function qr_householder(A)
    m, n = size(A)
    R = copy(A)
    V = [] # list of reflectors
    for j in 1:n
        v = copy(R[j:end, j])
        v[1] += sign(v[1]) * norm(v) # <---
        v = normalize(v)
        R[j:end,j:end] -= 2 * v * v' * R[j:end,j:end]
        push!(V, v)
    end
    V, R
end

function qr_chol(A)
    R = cholesky(A' * A).U
    Q = A / R
    Q, R
end

function qr_chol2(A)
    Q, R = qr_chol(A)
    Q, R1 = qr_chol(Q)
    Q, R1 * R
end

Krylov subspaces¶

Suppose we wish to solve

Ax=bA x = bAx=b
(1)

but only have the ability to apply the action of the AAA (we do not have access to its entries). A general approach is to work with approximations in a Krylov subspace, which has the form

Kn=[b∣Ab∣A2b∣⋯∣An−1b].K_n = \big[ b \big| Ab \big| A^2 b \big| \dotsm \big| A^{n-1} b \big] .Kn​=[b∣∣​Ab∣∣​A2b∣∣​⋯∣∣​An−1b].
(2)

This matrix is horribly ill-conditioned and cannot stably be computed as written. Instead, we seek an orthogonal basis QnQ_nQn​ that spans the same space as KnK_nKn​. We could write this as a factorization

Kn=QnRnK_n = Q_n R_nKn​=Qn​Rn​
(3)

where the first column q1=b/∥b∥q_1 = b / \lVert b \rVertq1​=b/∥b∥. The RnR_nRn​ is unnecessary and hopelessly ill-conditioned, so a slightly different procedure is used.

Arnoldi iteration¶

The Arnoldi iteration applies orthogonal similarity transformations to reduce AAA to Hessenberg form, starting from a vector q1=b/∥b∥q_1 = b/\lVert b \rVertq1​=b/∥b∥,

A=QHQT.A = Q H Q^T .A=QHQT.
(4)

Let’s multiply on the right by QQQ and examine the first nnn columns,

AQn=Qn+1HnA Q_n = Q_{n+1} H_nAQn​=Qn+1​Hn​
(5)

where HnH_nHn​ is an (n+1)×n(n+1) \times n(n+1)×n Hessenberg matrix.

GMRES¶

AQn=Qn+1HnA Q_n = Q_{n+1} H_nAQn​=Qn+1​Hn​
(6)

GMRES (Generalized Minimum Residual) minimizes

∥Ax−b∥\lVert A x - b \rVert∥Ax−b∥
(7)

over the subspace QnQ_nQn​. I.e., x=Qnyx = Q_n yx=Qn​y for some yyy. By the Arnoldi recurrence, this is equivalent to

∥Qn+1Hny−b∥\lVert Q_{n+1} H_n y - b \lVert∥Qn+1​Hn​y−b∥
(8)

which can be solved by minimizing

∥Hny−Qn+1Tb∥.\lVert H_n y - Q_{n+1}^T b \rVert .∥Hn​y−Qn+1T​b∥.
(9)

Since q1=b/∥b∥q_1 = b/\lVert b \lVertq1​=b/∥b∥, the least squares problem is to minimize

∥Hny−∥b∥e1∥.\Big\lVert H_n y - \lVert b \rVert e_1 \Big\rVert .∥∥​Hn​y−∥b∥e1​∥∥​.
(10)

The solution of this least squares problem is achieved by incrementally updating a QRQRQR factorization of HnH_nHn​.

Notes¶

  • The solution xnx_nxn​ constructed by GMRES at iteration nnn is not explicitly available. If a solution is needed, it must be constructed by solving the (n+1)×n(n+1)\times n(n+1)×n least squares problem and forming the solution as a linear combination of the nnn vectors QnQ_nQn​. The leading cost is 2mn2mn2mn where m≫nm \gg nm≫n.

  • The residual vector rn=Axn−br_n = A x_n - brn​=Axn​−b is not explicitly available in GMRES. To compute it, first build the solution xn=Qnynx_n = Q_n y_nxn​=Qn​yn​.

  • GMRES minimizes the 2-norm of the residual ∥rn∥\lVert r_n \rVert∥rn​∥ which is equivalent to the ATAA^T AATA norm of the error ∥xn−x∗∥ATA\lVert x_n - x_* \rVert_{A^T A}∥xn​−x∗​∥ATA​.

More notes on GMRES¶

  • GMRES needs to store the full QnQ_nQn​, which is unaffordable for large nnn (many iterations). The standard solution is to choose a “restart” kkk and to discard QnQ_nQn​ and start over with an initial guess xkx_kxk​ after each kkk iterations. This algorithm is called GMRES(k). PETSc’s default solver is GMRES(30) and the restart can be controlled using the run-time option -ksp_gmres_restart.

  • Most implementations of GMRES use classical Gram-Schmidt because it is much faster in parallel (one reduction per iteration instead of nnn reductions per iteration). The PETSc option -ksp_gmres_modifiedgramschmidt can be used when you suspect that classical Gram-Schmidt may be causing instability.

  • There is a very similar (and older) algorithm called GCR that maintains xnx_nxn​ and rnr_nrn​. This is useful, for example, if a convergence tolerance needs to inspect individual entries. GCR requires 2n2n2n vectors instead of nnn vectors, and can tolerate a nonlinear preconditioner. FGMRES is a newer algorithm with similar properties to GCR.

Condition numbers for matrices¶

We may have informally referred to a matrix as “ill-conditioned” when the columns are nearly linearly dependent, but let’s make this concept for precise. Recall the definition of (relative) condition number:

κ=max⁡δx∣δf∣/∣f∣∣δx∣/∣x∣.\kappa = \max_{\delta x} \frac{|\delta f|/|f|}{|\delta x|/|x|} .κ=δxmax​∣δx∣/∣x∣∣δf∣/∣f∣​.
(11)

We understood this definition for scalar problems, but it also makes sense when the inputs and/or outputs are vectors (or matrices, etc.) and absolute value is replaced by vector (or matrix) norms. Consider matrix-vector multiplication, for which f(x)=Axf(x) = A xf(x)=Ax.

κ(A)=max⁡δx∥A(x+δx)−Ax∥/∥Ax∥∥δx∥/∥x∥=max⁡δx∥Aδx∥∥δx∥ ∥x∥∥Ax∥=∥A∥∥x∥∥Ax∥.\kappa(A) = \max_{\delta x} \frac{\lVert A (x+\delta x) - A x \rVert/\lVert A x \rVert}{\lVert \delta x\rVert/\lVert x \rVert} = \max_{\delta x} \frac{\lVert A \delta x \rVert}{\lVert \delta x \rVert} \, \frac{\lVert x \rVert}{\lVert A x \rVert} = \lVert A \rVert \frac{\lVert x \rVert}{\lVert A x \rVert} .κ(A)=δxmax​∥δx∥/∥x∥∥A(x+δx)−Ax∥/∥Ax∥​=δxmax​∥δx∥∥Aδx∥​∥Ax∥∥x∥​=∥A∥∥Ax∥∥x∥​.
(12)

There are two problems here:

  • I wrote κ(A)\kappa(A)κ(A) but my formula depends on xxx.

  • What is that ∥A∥\lVert A \rVert∥A∥ beastie?

Matrix norms induced by vector norms¶

Vector norms are built into the linear space (and defined in term of the inner product). Matrix norms are induced by vector norms, according to

∥A∥=max⁡x≠0∥Ax∥∥x∥.\lVert A \rVert = \max_{x \ne 0} \frac{\lVert A x \rVert}{\lVert x \rVert} .∥A∥=x=0max​∥x∥∥Ax∥​.
(13)

  • This equation makes sense for non-square matrices -- the vector norms of the input and output spaces may differ.

  • Due to linearity, all that matters is direction of xxx, so it could equivalently be written

∥A∥=max⁡∥x∥=1∥Ax∥.\lVert A \rVert = \max_{\lVert x \rVert = 1} \lVert A x \rVert .∥A∥=∥x∥=1max​∥Ax∥.
(14)

The formula makes sense, but still depends on xxx.¶

κ(A)=∥A∥∥x∥∥Ax∥\kappa(A) = \lVert A \rVert \frac{\lVert x \rVert}{\lVert Ax \rVert}κ(A)=∥A∥∥Ax∥∥x∥​
(15)

Consider the matrix

A=[1000].A = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} .A=[10​00​].
(16)

Condition number of the matrix¶

The condition number of matrix-vector multiplication depends on the vector. The condition number of the matrix is the worst case (maximum) of the condition number for any vector, i.e.,

κ(A)=max⁡x≠0∥A∥∥x∥∥Ax∥.\kappa(A) = \max_{x \ne 0} \lVert A \rVert \frac{\lVert x \rVert}{\lVert A x \rVert} .κ(A)=x=0max​∥A∥∥Ax∥∥x∥​.
(17)

If AAA is invertible, then we can rephrase as

κ(A)=max⁡x≠0∥A∥∥A−1(Ax)∥∥Ax∥=max⁡Ax≠0∥A∥∥A−1(Ax)∥∥Ax∥=∥A∥∥A−1∥.\kappa(A) = \max_{x \ne 0} \lVert A \rVert \frac{\lVert A^{-1} (A x) \rVert}{\lVert A x \rVert} = \max_{A x \ne 0} \lVert A \rVert \frac{\lVert A^{-1} (A x) \rVert}{\lVert A x \rVert} = \lVert A \rVert \lVert A^{-1} \rVert .κ(A)=x=0max​∥A∥∥Ax∥∥A−1(Ax)∥​=Ax=0max​∥A∥∥Ax∥∥A−1(Ax)∥​=∥A∥∥A−1∥.
(18)

Evidently multiplying by a matrix is just as ill-conditioned of an operation as solving a linear system using that matrix.
