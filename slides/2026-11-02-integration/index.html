function vander_legendre(x, k=nothing)
    if isnothing(k)
        k = length(x) # Square by default
    end
    m = length(x)
    Q = ones(m, k)
    Q[:, 2] = x
    for n in 1:k-2
        Q[:, n+2] = ((2*n + 1) * x .* Q[:, n+1] - n * Q[:, n]) / (n + 1)
    end
    Q
end

Fundamental Theorem of Calculus¶

Let f(x)f(x)f(x) be a continuous function and define F(x)F(x)F(x) by

F(x)=∫axf(s)ds.F(x) = \int_a^x f(s) ds .F(x)=∫ax​f(s)ds.
(2)

Then F(x)F(x)F(x) is uniformly continuous, differentiable, and

F′(x)=f(x).F'(x) = f(x) .F′(x)=f(x).
(3)

We say that FFF is an antiderivative of fff. This implies that

∫abf(x)dx=F(b)−F(a).\int_a^b f(x) dx = F(b) - F(a) .∫ab​f(x)dx=F(b)−F(a).
(4)

We will test the accuracy of our integration schemes using an antiderivative provided in our tests.

Midpoint method¶

function fint_midpoint(f, a, b; n=20)
    dx = (b - a) / n
    x = LinRange(a + dx/2, b - dx/2, n)
    sum(f.(x)) * dx
end

function plot_accuracy(fint, tests, ns; ref=[1,2])
    a, b = -2, 2

Trapezoid in code¶

function fint_trapezoid(f, a, b; n=20)
    dx = (b - a) / (n - 1)
    x = LinRange(a, b, n)
    fx = f.(x)
    fx[1] /= 2
    fx[end] /= 2
    sum(fx) * dx
end

Extrapolation math¶

The trapezoid rule with nnn points has an interval spacing of h=1/(n−1)h = 1/(n-1)h=1/(n−1). Let IhI_hIh​ be the value of the integral approximated using an interval hhh. We have numerical evidence that the leading error term is O(h2)O(h^2)O(h2), i.e.,

Ih−I0=ch2+O(h3)I_h - I_0 = c h^2 + O(h^3)Ih​−I0​=ch2+O(h3)
(6)

for some as-yet unknown constant ccc that will depend on the function being integrated and the domain of integration. If we can determine ccc from two approximations, say IhI_hIh​ and I2hI_{2h}I2h​, then we can extrapolate to h=0h=0h=0. For sufficiently small hhh, we can neglect O(h3)O(h^3)O(h3) and write

Ih−I0=ch2I2h−I0=c(2h)2.\begin{split} I_h - I_0 &= c h^2 \\ I_{2h} - I_0 &= c (2h)^2 . \end{split}Ih​−I0​I2h​−I0​​=ch2=c(2h)2.​
(7)

Subtracting these two lines, we have

Ih−I2h=c(h2−4h2)I_{h} - I_{2h} = c (h^2 - 4 h^2)Ih​−I2h​=c(h2−4h2)
(8)

which can be solved for ccc as

c=Ih−I2hh2−4h2.c = \frac{I_{h} - I_{2h}}{h^2 - 4 h^2} .c=h2−4h2Ih​−I2h​​.
(9)

Substituting back into the first equation, we solve for I0I_0I0​ as

I0=Ih−ch2=Ih+Ih−I2h4−1.I_0 = I_h - c h^2 = I_h + \frac{I_{h} - I_{2h}}{4 - 1} .I0​=Ih​−ch2=Ih​+4−1Ih​−I2h​​.

This is called Richardson extrapolation.

Extrapolation code¶

function fint_richardson(f, a, b; n=20)
    n = div(n, 2) * 2 + 1
    h = (b - a) / (n - 1)
    x = LinRange(a, b, n)
    fx = f.(x)
    fx[[1, end]] /= 2
    I_h = sum(fx) * h
    I_2h = sum(fx[1:2:end]) * 2h
    I_h + (I_h - I_2h) / 3
end
plot_accuracy_h(fint_richardson, tests, 2 .^ (2:10), ref=1:5)
