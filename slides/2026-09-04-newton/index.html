Convergence classes¶

A convergent rootfinding algorithm produces a sequence of approximations xkx_kxk​ such that

lim⁡k→∞xk→x∗\lim_{k \to \infty} x_k \to x_*k→∞lim​xk​→x∗​
(1)

where f(x∗)=0f(x_*) = 0f(x∗​)=0. For analysis, it is convenient to define the errors ek=xk−x∗e_k = x_k - x_*ek​=xk​−x∗​. We say that an iterative algorithm is qqq-linearly convergent if

lim⁡k→∞∣ek+1∣/∣ek∣=ρ<1.\lim_{k \to \infty} |e_{k+1}| / |e_k| = \rho < 1.k→∞lim​∣ek+1​∣/∣ek​∣=ρ<1.
(2)

(The qqq is for “quotient”.) A smaller convergence factor ρ\rhoρ represents faster convergence. A slightly weaker condition (rrr-linear convergence or just linear convergence) is that

∣ek∣≤ϵk|e_k| \le \epsilon_k∣ek​∣≤ϵk​
(3)

for all sufficiently large kkk when the sequence {ϵk}\{\epsilon_k\}{ϵk​} converges qqq-linearly to 0.

Remarks on bisection¶

  • Specifying an interval is often inconvenient

  • An interval in which the function changes sign guarantees convergence (robustness)

  • No derivative information is required

  • If bisection works for f(x)f(x)f(x), then it works and gives the same accuracy for f(x)σ(x)f(x) \sigma(x)f(x)σ(x) where σ(x)>0\sigma(x) > 0σ(x)>0.

  • Roots of even degree are problematic

  • A bound on the solution error is directly available

  • The convergence rate is modest -- one iteration per bit of accuracy

Newton-Raphson Method¶

Much of numerical analysis reduces to Taylor series, the approximation

f(x)=f(x0)+f′(x0)(x−x0)+f′′(x0)(x−x0)2/2+⋯⏟O((x−x0)3)f(x) = f(x_0) + f'(x_0) (x-x_0) + f''(x_0) (x - x_0)^2 / 2 + \underbrace{\dotsb}_{O((x-x_0)^3)}f(x)=f(x0​)+f′(x0​)(x−x0​)+f′′(x0​)(x−x0​)2/2+O((x−x0​)3)⋯​​
(4)

centered on some reference point x0x_0x0​.

In numerical computation, it is exceedingly rare to look beyond the first-order approximation

f~x0(x)=f(x0)+f′(x0)(x−x0).\tilde f_{x_0}(x) = f(x_0) + f'(x_0)(x - x_0) .f~​x0​​(x)=f(x0​)+f′(x0​)(x−x0​).
(5)

Since f~x0(x)\tilde f_{x_0}(x)f~​x0​​(x) is a linear function, we can explicitly compute the unique solution of f~x0(x)=0\tilde f_{x_0}(x) = 0f~​x0​​(x)=0 as

x=x0−f(x0)f′(x0).x = x_0 - \frac{f(x_0)}{f'(x_0)} .x=x0​−f′(x0​)f(x0​)​.
(6)

This is Newton’s Method (aka Newton-Raphson or Newton-Raphson-Simpson) for finding the roots of differentiable functions.

An implementation¶

function newton(f, fp, x0; tol=1e-8, verbose=false)
    x = x0
    for k in 1:100 # max number of iterations
        fx = f(x)
        fpx = fp(x)
        if verbose
            println("[$k] x=$x  f(x)=$fx  f'(x)=$fpx")
        end
        if abs(fx) < tol
            return x, fx, k
        end
        x = x - fx / fpx
    end  
end

xk+1=g(xk)x_{k+1} = g(x_k)xk+1​=g(xk​)

xk+1−x∗=g(xk)−g(x∗)=g′(ck)(xk−x∗)x_{k+1} - x_* = g(x_k) - g(x_*) = g'(c_k) (x_k - x_*)xk+1​−x∗​=g(xk​)−g(x∗​)=g′(ck​)(xk​−x∗​)

Aside: Big OOO (“big oh”) notation¶

Limit n→∞n\to\inftyn→∞¶

We’d say an algorithm costs O(n2)O(n^2)O(n2) if its running time on input of size nnn is less than cn2c n^2cn2 for some constant ccc and sufficiently large nnn.

Sometimes we write cost⁡(algorithm,n)=O(n2)\operatorname{cost}(\texttt{algorithm}, n) = O(n^2)cost(algorithm,n)=O(n2) or (preferably) cost⁡(algorithm)∈O(n2)\operatorname{cost}(\texttt{algorithm}) \in O(n^2)cost(algorithm)∈O(n2).

Note that O(log⁡n)⊂O(n)⊂O(nlog⁡n)⊂O(n2)⊂⋯O(\log n) \subset O(n) \subset O(n\log n) \subset O(n^2) \subset \dotsbO(logn)⊂O(n)⊂O(nlogn)⊂O(n2)⊂⋯ so it’s correct to say “binary search is in O(n2)O(n^2)O(n2)”, even though a sharper statement is also true.

How does it work?¶

Let’s look at the last line

y  = y * ( threehalfs - ( x2 * y * y ) );   // 1st iteration

We want a function f(y)f(y)f(y) such that f(1/x)=0f(1/\sqrt{x}) = 0f(1/x​)=0. One such function is

f(y)=1/y2−x,f′(y)=−2/y3.f(y) = 1/y^2 - x, \quad f'(y) = -2/y^3.f(y)=1/y2−x,f′(y)=−2/y3.
(27)

There are others, e.g.,

f1(y)=y2−1/x,f′(y)=2y,f_1(y) = y^2 - 1/x,\quad f'(y) = 2 y,f1​(y)=y2−1/x,f′(y)=2y,
(28)
