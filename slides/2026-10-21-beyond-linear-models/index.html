using LinearAlgebra
using Plots
default(linewidth=4, legendfontsize=12)

function vander(x, k=nothing)
    if isnothing(k)
        k = length(x)
    end
    m = length(x)
    V = ones(m, k)
    for j in 2:k
        V[:, j] = V[:, j-1] .* x
    end
    V
end

function vander_chebyshev(x, n=nothing)
    if isnothing(n)
        n = length(x) # Square by default
    end
    m = length(x)
    T = ones(m, n)
    if n > 1
        T[:, 2] = x
    end
    for k in 3:n
        #T[:, k] = x .* T[:, k-1]
        T[:, k] = 2 * x .* T[:,k-1] - T[:, k-2]
    end
    T
end

function chebyshev_regress_eval(x, xx, n)
    V = vander_chebyshev(x, n)
    vander_chebyshev(xx, n) / V
end

runge(x) = 1 / (1 + 10*x^2)

Bias-variance tradeoff¶

The expected error in our approximation f^(x)\hat f(x)f^​(x) of noisy data y=f(x)+ϵy = f(x) + \epsilony=f(x)+ϵ (with ϵ∼N(0,σ)\epsilon \sim \mathcal N(0, \sigma)ϵ∼N(0,σ)), can be decomposed as

E[(f^(x)−y)2]=σ2+(E[f^(x)]−f(x)⏟Bias)2+E[f^(x)2]−E[f^(x)]2⏟Variance.E[(\hat f(x) - y)^2] = \sigma^2 + \big(\underbrace{E[\hat f(x)] - f(x)}_{\text{Bias}}\big)^2 + \underbrace{E[\hat f(x)^2] - E[\hat f(x)]^2}_{\text{Variance}} .E[(f^​(x)−y)2]=σ2+(BiasE[f^​(x)]−f(x)​​)2+VarianceE[f^​(x)2]−E[f^​(x)]2​​.
(1)

The σ2\sigma^2σ2 term is irreducible error (purely due to observation noise), but bias and variance can be controlled by model selection. More complex models are more capable of expressing the underlying function f(x)f(x)f(x), thus are capable of reducing bias. However, they are also more affected by noise, thereby increasing variance.

Interpretation¶

  • Re-run the cell above for different values of degree. (Set it back to a number around 7 to 10 before moving on.)

  • Low-degree polynomials are not rich enough to capture the peak of the function.

  • As we increase degree, we are able to resolve the peak better, but see more eratic behavior near the ends of the interval. This erratic behavior is overfitting, which we’ll quantify as variance.

  • This tradeoff is fundamental: richer function spaces are more capable of approximating the functions we want, but they are more easily distracted by noise.

Why do we call it a linear model?¶

We are currently working with algorithms that express the regression as a linear function of the model parameters. That is, we search for coefficients c=[c1,c2,… ]Tc = [c_1, c_2, \dotsc]^Tc=[c1​,c2​,…]T such that

V(x)c≈yV(x) c \approx yV(x)c≈y
(2)

where the left hand side is linear in ccc. In different notation, we are searching for a predictive model

f^(xi,c)≈yi for all (xi,yi)\hat f(x_i, c) \approx y_i \text{ for all $(x_i, y_i)$}f^​(xi​,c)≈yi​ for all (xi​,yi​)
(3)

that is linear in ccc.

Standard assumptions for regression¶

(the way we’ve been doing it so far)¶

  1. The independent variables xxx are error-free

  2. The prediction (or “response”) f(x,c)f(x,c)f(x,c) is linear in ccc

  3. The noise in the measurements yyy is independent (uncorrelated)

  4. The noise in the measurements yyy has constant variance

There are reasons why all of these assumptions may be undesirable in practice, thus leading to more complicated methods.

Anscombe’s quartet¶

Loss functions¶

The error in a single prediction f(xi,c)f(x_i,c)f(xi​,c) of an observation (xi,yi)(x_i, y_i)(xi​,yi​) is often measured as

12(f(xi,c)−yi)2,\frac 1 2 \big( f(x_i, c) - y_i \big)^2,21​(f(xi​,c)−yi​)2,
(4)

which turns out to have a statistical interpretation when the noise is normally distributed. It is natural to define the error over the entire data set as

L(c;x,y)=∑i12(f(xi,c)−yi)2=12∥f(x,c)−y∥2\begin{align} L(c; x, y) &= \sum_i \frac 1 2 \big( f(x_i, c) - y_i \big)^2 \\ &= \frac 1 2 \lVert f(x, c) - y \rVert^2 \end{align}L(c;x,y)​=i∑​21​(f(xi​,c)−yi​)2=21​∥f(x,c)−y∥2​​
(5)

where I’ve used the notation f(x,c)f(x,c)f(x,c) to mean the vector resulting from gathering all of the outputs f(xi,c)f(x_i, c)f(xi​,c). The function LLL is called the “loss function” and is the key to relaxing the above assumptions.

Variational notation¶

It’s convenient to express derivatives in terms of how they act on an infinitessimal perturbation. So we might write

δ(xTy)=(δx)Ty+xT(δy).\delta(\mathbf x^T \mathbf y) = (\delta \mathbf x)^T \mathbf y + \mathbf x^T (\delta \mathbf y).δ(xTy)=(δx)Ty+xT(δy).

Optimization¶

Given data (x,y)(x,y)(x,y) and loss function L(c;x,y)L(c; x,y)L(c;x,y), we wish to find the coefficients ccc that minimize the loss, thus yielding the “best predictor” (in a sense that can be made statistically precise). I.e.,

cˉ=arg⁡min⁡cL(c;x,y).\bar c = \arg\min_c L(c; x,y) .cˉ=argcmin​L(c;x,y).
(17)

It is usually desirable to design models such that the loss function is differentiable with respect to the coefficients ccc, because this allows the use of more efficient optimization methods. Recall that our forward model is given in terms of the Vandermonde matrix,

f(x,c)=V(x)cf(x, c) = V(x) cf(x,c)=V(x)c
(18)

and thus

∂f∂c=V(x).\frac{\partial f}{\partial c} = V(x) .∂c∂f​=V(x).
(19)

We can now differentiate our loss function

L(c;x,y)=12∥f(x,c)−y∥2=12∑i(f(xi,c)−yi)2L(c; x, y) = \frac 1 2 \lVert f(x, c) - y \rVert^2 = \frac 1 2 \sum_i (f(x_i,c) - y_i)^2L(c;x,y)=21​∥f(x,c)−y∥2=21​i∑​(f(xi​,c)−yi​)2
(20)

term-by-term as

∇cL(c;x,y)=∂L(c;x,y)∂c=∑i(f(xi,c)−yi)∂f(xi,c)∂c=∑i(f(xi,c)−yi)V(xi)\begin{align} \nabla_c L(c; x,y) = \frac{\partial L(c; x,y)}{\partial c} &= \sum_i \big( f(x_i, c) - y_i \big) \frac{\partial f(x_i, c)}{\partial c} \\ &= \sum_i \big( f(x_i, c) - y_i \big) V(x_i) \end{align}∇c​L(c;x,y)=∂c∂L(c;x,y)​​=i∑​(f(xi​,c)−yi​)∂c∂f(xi​,c)​=i∑​(f(xi​,c)−yi​)V(xi​)​​

where V(xi)V(x_i)V(xi​) is the iiith row of V(x)V(x)V(x).

Alternative derivative¶

Alternatively, we can take a more linear algebraic approach to write the same expression is

∇cL(c;x,y)=(f(x,c)−y)TV(x)=(V(x)c−y)TV(x)=V(x)T(V(x)c−y).\begin{align} \nabla_c L(c; x,y) &= \big( f(x,c) - y \big)^T V(x) \\ &= \big(V(x) c - y \big)^T V(x) \\ &= V(x)^T \big( V(x) c - y \big) . \end{align}∇c​L(c;x,y)​=(f(x,c)−y)TV(x)=(V(x)c−y)TV(x)=V(x)T(V(x)c−y).​​
